Stacks: LIFO Data Structure

A stack is a collection where you can only add and remove from the TOP. Last In, First Out (LIFO). All operations — push, pop, peek — are O(1). Used in undo systems, compilers, and recursion.

💡 Key Idea: The function call stack in your C program IS a real stack. Every function call pushes a frame; every return pops one. Stack overflow = pushing too many frames (infinite recursion) until memory runs out.

🌍 Real-World Applications

↩️
Text Editor Undo (Ctrl+Z)
Every keystroke or edit is pushed onto a stack. Ctrl+Z pops the last action and reverses it. Ctrl+Y (redo) pops a second stack. This is exactly the SRS EditHistory module you built!
🔧 Stack: push on edit, pop on undo
🌐
Browser Back Button
Every page you navigate to is pushed onto a stack. The back button pops the current page and returns to the previous. Forward button pushes to a second (forward) stack.
🔧 Stack of URL history
⚙️
Compiler Bracket Matching
Compilers use a stack to verify that ({[]}) are properly matched. Every ( [ { pushes; every ) ] } pops and checks. If the stack is empty at the end with a match — code is valid!
🔧 Character stack for syntax validation
📞
Function Call Stack
Every function call in any program pushes a 'stack frame' (local variables, return address). When the function returns, its frame is popped. Stack overflow = too many recursive calls = frames fill RAM.
