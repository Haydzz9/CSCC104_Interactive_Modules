Recursion and Recursive Problem Solving

Recursion solves a problem by breaking it into a smaller version of the same problem. Every recursive solution has two parts: a base case (stop) and a recursive case (shrink and repeat).

💡 Key Idea: Recursion is NOT magic — it uses the call stack. Each recursive call pushes a new frame. The base case pops frames back. Drawing the call tree reveals exactly what happens at every level.

🌍 Real-World Applications

📂
File System Traversal
'List all files in this folder and all sub-folders recursively' is literally a recursive algorithm: process current folder, then recursively call for each sub-folder. Your OS uses this every time you search.
🔧 DFS recursion on directory tree
🎮
Game AI (Minimax)
Chess engines evaluate moves recursively — 'if I move here, opponent can move there, then I can respond...' Minimax explores the game tree recursively to depth 10-20 to find the best move.
🔧 Recursive game tree search
🧬
DNA Sequence Analysis
Finding similarities between two DNA sequences uses recursive dynamic programming (Smith-Waterman algorithm). Each cell in the DP table recursively depends on previous cells.
🔧 Recursive memoization for sequence alignment
🌐
Web Page Crawling
Google's crawler visits a page, finds all links, then recursively visits each linked page, and each page those link to. The entire web graph is explored recursively with DFS.
🔧 Recursive DFS graph traversal
