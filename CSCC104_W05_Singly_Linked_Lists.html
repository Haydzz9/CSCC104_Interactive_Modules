Singly Linked Lists

A linked list consists of nodes scattered anywhere in memory, connected by pointers. Unlike arrays, it grows dynamically and inserts in O(1) — but searching takes O(n).

💡 Key Idea: Arrays: fast access (O(1)), slow insert/delete (O(n)). Linked Lists: slow access (O(n)), fast insert/delete (O(1)) given a node pointer. Choose based on your most frequent operation.

🌍 Real-World Applications

🌐
Browser History
Each webpage visit is a node. The browser's back/forward navigation traverses the list. New pages are inserted at the head (current), old ones deleted when history is cleared.
🔧 Singly linked list of page URLs
🎵
Music Playlist
Songs in a playlist are linked nodes. Adding a song at any position, removing a song, or rearranging requires only pointer changes — no shifting like an array would need.
🔧 Linked list for O(1) song insertion/removal
🖨️
Print Spooler
Print jobs are added to a queue (linked list). The printer dequeues jobs one by one. New jobs can be added at any time without rebuilding the queue.
🔧 Linked list for dynamic job queue
💬
Chat Message History
WhatsApp and Telegram store recent messages as a doubly linked list — new messages insert at the tail, and scrolling up traverses backward through history.
