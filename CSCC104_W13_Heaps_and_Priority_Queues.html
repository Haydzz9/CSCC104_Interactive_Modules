Heaps and Priority Queues

A heap is a complete binary tree stored in an array. Min-Heap: parent ≤ children — minimum always at root. All insert and extract operations are O(log n) due to the tree height.

💡 Key Idea: Heap indices: parent(i) = (i-1)/2, left(i) = 2i+1, right(i) = 2i+2. This formula maps a complete binary tree perfectly onto an array — NO pointers needed! This is more memory-efficient than BST nodes.

🌍 Real-World Applications

🚑
Hospital Emergency Triage
Patients are prioritized by severity (not arrival time). A min-heap ensures the most critical patient is always at the top. Inserting a new critical patient is O(log n) — fast even in emergencies.
🔧 Min-heap for priority-based patient queue
🖥️
CPU Task Scheduler
Operating systems (Linux CFS scheduler) use a Red-Black tree (heap-like) to prioritize processes by 'virtual runtime.' The process with the least CPU time is always next — O(log n) scheduling decision.
🔧 Heap-based O(log n) process selection
📡
Dijkstra's Shortest Path
Dijkstra's algorithm uses a min-heap (priority queue) to always expand the unvisited node with the smallest known distance. Without a heap, each expansion is O(n); with a heap it's O(log n) — critical for Google Maps.
🔧 Min-heap for O(log n) minimum distance extraction
🎯
Top-K Problems
'Find the 10 most popular videos on YouTube right now' — a min-heap of size 10. For each new video, if it's more popular than the min, replace and siftUp. Final heap contains the top 10 in O(n log k).
