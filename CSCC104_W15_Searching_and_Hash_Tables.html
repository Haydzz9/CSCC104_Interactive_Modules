Searching & Hash Tables

Binary search achieves O(log n) on sorted arrays by eliminating half the search space each step. Hash tables achieve O(1) average lookup by mapping keys directly to array positions using a hash function.

💡 Key Idea: Hash tables are the most powerful lookup structure — O(1) average for insert, search, and delete. The trade-off: no sorted order. BST gives O(log n) but maintains order. Choose based on whether you need range queries.

🌍 Real-World Applications

🔐
Password Storage
Websites store hashed passwords (SHA-256, bcrypt) in hash tables. When you log in, your password is hashed and compared to the stored hash — never stored in plain text. O(1) lookup.
🔧 Hash function for secure password comparison
📚
Python & JavaScript Dictionaries
Python dict and JavaScript Map are hash tables. `student['name']` is O(1). These are among the most-used data structures in all of programming — used millions of times per second worldwide.
🔧 Hash table for O(1) key-value storage
🧬
DNA Pattern Matching
Finding a 20-base DNA pattern in a 3-billion-base genome uses Rabin-Karp: hash the pattern, slide a window computing rolling hash values, compare only when hashes match — O(n) instead of O(n×m) brute force.
🔧 Rolling hash for efficient pattern matching
🌐
DNS Resolution
Typing 'google.com' triggers a DNS lookup: hash the domain name, find the IP in the DNS hash table. Billions of lookups happen per day — only possible in O(1) with hash tables.
