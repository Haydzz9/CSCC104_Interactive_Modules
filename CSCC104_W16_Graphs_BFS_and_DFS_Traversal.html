Graphs: BFS and DFS Traversal

Graphs model anything with connections: cities, social networks, course prerequisites, the internet. BFS finds shortest paths; DFS detects cycles and builds spanning trees.

💡 Key Idea: BFS uses a QUEUE → explores neighbors level by level → shortest path. DFS uses a STACK (or recursion) → goes as deep as possible → detects cycles, topological sort. Both are O(V + E).

🌍 Real-World Applications

🗺️
Google Maps Navigation
Finding the shortest driving route is BFS/Dijkstra's on a weighted road graph. Each intersection is a vertex; each road is a weighted edge. Google processes millions of queries per second on this graph.
🔧 BFS + Dijkstra's for shortest weighted path
👥
LinkedIn Connections
'People You May Know' is BFS on a social graph — find all 2nd-degree connections (friends of friends). Each hop in the graph widens the search one level. LinkedIn runs BFS on 900M+ node graphs.
🔧 BFS for k-degree connection discovery
🎓
Course Prerequisite Validation
Universities model course dependencies as directed graphs. DFS detects cycles (impossible prerequisites like A requires B and B requires A). Topological sort gives a valid course sequence.
🔧 DFS cycle detection + topological sort
🌐
Web Crawler (Google Spider)
Google's crawler starts at seed URLs and DFS/BFS through links to discover the web. PageRank computes importance by analyzing the link graph — a 100-billion-node graph processed in distributed fashion.
🔧 DFS/BFS traversal of the web link graph
