Queues: FIFO Data Structure

A queue serves the first person who arrived — First In, First Out. Unlike stacks, insertion is at the REAR and removal is at the FRONT. All operations are O(1).

💡 Key Idea: BFS (Breadth-First Search) on graphs uses a QUEUE. This is WHY BFS explores nodes level by level — a queue processes them in the order they were discovered, closest first.

🌍 Real-World Applications

🏫
University Enrollment System
Students submit enrollment applications in order. The registrar processes them FIFO — first to apply is first to be enrolled. This is exactly the SRS-07 EnrollmentQueue you built!
🔧 Queue: enqueue on application, dequeue on processing
🖨️
Printer Spooler
When multiple users send documents to one printer, jobs queue up. The printer processes them FIFO — first document sent is first printed. Job priority can be added for a priority queue.
🔧 FIFO queue of print jobs
🚦
Operating System CPU Scheduling
Round-Robin scheduling (used in Linux, Windows) puts processes in a queue. Each gets a time slice; if not done, it rejoins the rear. Fairness guaranteed by FIFO.
🔧 Queue for fair process scheduling
📦
Online Order Processing (Shopee/Lazada)
Orders are processed in the sequence received. Warehouse systems use queues to manage picking, packing, and shipping — ensuring no order gets skipped or unfairly delayed.
