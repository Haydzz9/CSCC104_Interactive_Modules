Doubly & Circular Linked Lists

Doubly linked lists add a prev pointer to each node, enabling O(1) deletion given any node pointer and bidirectional traversal. Circular lists form loops for round-robin applications.

💡 Key Idea: The key upgrade from SLL to DLL: O(1) deletion requires ONLY the node pointer — no predecessor search needed. This makes DLL essential for LRU caches and text editor cursors.

🌍 Real-World Applications

📄
Text Editor Cursor
A text editor's cursor navigates a DLL of characters. Moving left follows prev pointers; right follows next. Inserting or deleting a character at cursor position is O(1).
🔧 DLL for O(1) cursor insertion/deletion
🔄
Browser Tab Switching
Browser tabs form a circular doubly linked list. Ctrl+Tab cycles forward; Ctrl+Shift+Tab cycles backward. When you close a tab, its DLL node is removed in O(1).
🔧 Circular DLL for cyclic tab navigation
⌛
LRU Cache (Least Recently Used)
An LRU cache uses a DLL where the most recently used item moves to the front. When the cache is full, the tail (least recently used) is removed in O(1). Used in CPU cache and web browsers.
🔧 DLL for O(1) node promotion and eviction
🎮
Undo/Redo with History Tree
Advanced editors (Photoshop, Vim) use a DLL of states for linear undo/redo. Each node points to previous and next states, allowing full bidirectional history traversal.
🔧 DLL for bidirectional state history
