Dynamic Programming & Greedy Algorithms

Dynamic Programming solves complex problems by breaking them into overlapping subproblems, solving each once, and caching results. Greedy always picks the locally best option — faster but not always correct.

💡 Key Idea: The key question: does greedy give the OPTIMAL answer for this problem? If YES (activity selection, Dijkstra) — use greedy (faster). If NO (0/1 Knapsack, coin change with weird coins) — use DP.

🌍 Real-World Applications

💊
Drug Dosage Optimization
Finding the optimal combination of drugs with a fixed budget to maximize therapeutic effect — a 0/1 Knapsack problem. DP ensures no beneficial combination is missed by greedy selection.
🔧 0/1 Knapsack DP for optimal allocation
📡
Network Routing (Dijkstra)
Finding shortest paths in weighted networks uses a GREEDY approach — always expand the node with minimum known distance. Greedy works here because of optimal substructure in non-negative weighted graphs.
🔧 Greedy priority queue (where greedy IS optimal)
🎒
Airline Baggage Allowance
Packing maximum value into a 23kg weight limit is a Knapsack problem. DP finds the truly optimal set of items. Greedy (pick highest value/weight ratio) often works but can fail with indivisible items.
🔧 0/1 Knapsack DP for weight optimization
🎓
Scholarship Allocation
Given a budget and students with different scholarship costs and GWA scores, DP allocates scholarships to maximize total academic benefit. This is the SRS-15 Capstone module you built!
🔧 0/1 Knapsack DP for scholarship optimization
