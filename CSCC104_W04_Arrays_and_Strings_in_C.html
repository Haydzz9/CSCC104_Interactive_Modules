Arrays and Strings in C

Arrays are the simplest data structure — contiguous memory slots giving O(1) access by index. They are the backbone of most algorithms, but have a fixed size and O(n) insert/delete.

💡 Key Idea: arr[i] = base_address + i × sizeof(element). This formula means ANY element can be reached in exactly ONE step — O(1) — regardless of array size. No other structure beats this for random access.

🌍 Real-World Applications

🖼️
Digital Images (Pixels)
A 4K image is a 3840×2160 2D array. Each cell stores RGB values. Image filters (blur, sharpen) access adjacent pixels in O(1) — possible only because arrays have direct index access.
🔧 2D array for pixel grid, O(1) pixel access
📊
Spreadsheets (Excel/Google Sheets)
Every spreadsheet is a 2D array of cells. Excel's lookup functions (VLOOKUP, INDEX/MATCH) navigate this array. Array formulas compute millions of values instantly.
🔧 2D array with O(1) cell access by row/column
🎵
Audio Processing
Sound is stored as an array of samples (44,100 per second for CD quality). Equalizers, filters, and audio effects process these arrays in real time — O(n) per audio frame.
🔧 1D array of audio samples, FFT algorithm
📈
Stock Market Data
Historical stock prices are stored in arrays indexed by time. Chart software accesses any date's price in O(1) and computes moving averages with a sliding window over the array.
🔧 Array for time-series data, O(1) date lookup
